# Object_detection_from_DAS
Computer vision first project - Detecting Moving Objects in DAS Recordings

Detection and tracking of vehicles (trams, trucks, cars) in Distributed Acoustic Sensing
recordings from Jana Pawla II street, with velocity estimation, velocity-over-time profiles
and clustering of detected objects. Classical signal/image processing only
(NumPy, OpenCV, scikit-image, Matplotlib, Pillow) - no neural networks.

## Setup
The project is managed with [uv](https://docs.astral.sh/uv/) (Python 3.12, pinned in `.python-version`).
```bash
uv sync                                   # creates .venv, installs deps + dev group + `das` (editable)
uv run python scripts/extract_data.py
```
Without uv: `pip install -r requirements.txt && pip install -e .`
(`requirements.txt` is generated by `uv export --no-hashes --no-dev --no-emit-project -o requirements.txt`).

Dependencies: `uv add <pkg>` (algorithm - allowed libraries only!), `uv add --dev <pkg>` (tooling).

## Usage
```bash
uv run python scripts/run_eda.py                     # dataset statistics + figures
uv run python scripts/run_spectral.py                # FFT / STFT / f-k analysis
uv run python scripts/run_pipeline.py --segment all  # detection for configured 2-min segments
uv run python scripts/evaluate_synthetic.py          # metrics vs. synthetic ground truth
uv run python scripts/run_clustering.py              # clustering of detected objects
uv run python scripts/make_report_figures.py         # figures used in report/
uv run pytest                                        # tests (warnings are errors)
uv run jupyter lab                                   # notebooks / report
```

## Layout
- `src/das/` - library code (one module per processing stage)
- `scripts/` - command-line entry points
- `notebooks/` - exploratory notebooks
- `report/` - final report (`report.ipynb` -> `.html`/`.pdf`)
- `docs/` - flowchart, experiment log, references
- `data/`, `outputs/` - data and generated results (not versioned)
