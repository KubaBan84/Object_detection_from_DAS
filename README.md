# Object_detection_from_DAS
Computer vision first project - Detecting Moving Objects in DAS Recordings

Detection and tracking of vehicles (trams, trucks, cars) in Distributed Acoustic Sensing
recordings from Jana Pawla II street, with velocity estimation, velocity-over-time profiles
and clustering of detected objects. Classical signal/image processing only
(NumPy, OpenCV, scikit-image, Matplotlib, Pillow) - no neural networks.

## Setup
The project is managed with [uv](https://docs.astral.sh/uv/) (Python 3.12, pinned in `.python-version`).
```bash
uv sync                                   # creates .venv, installs deps + dev group + `das` (editable)
uv run python scripts/extract_data.py
```
Without uv: `pip install -r requirements.txt && pip install -e .`
(`requirements.txt` is generated by `uv export --no-hashes --no-dev --no-emit-project -o requirements.txt`).

Dependencies: `uv add <pkg>` (algorithm - allowed libraries only!), `uv add --dev <pkg>` (tooling).

## Usage
```bash
uv run python scripts/run_eda.py                     # dataset statistics + figures
uv run python scripts/run_spectral.py                # FFT / STFT / f-k analysis
uv run python scripts/run_enhancement.py             # Stages 4-5: energy images, f-k, filter bank
uv run python scripts/run_detection.py               # Stages 6-7: line detection + grouping
uv run python scripts/run_velocity.py                # Stages 8-9: velocities, tracks, v(t)
uv run python scripts/run_clustering.py              # Stage 10: object features + k-means clustering
uv run python scripts/evaluate_synthetic.py          # Stage 11: metrics vs. synthetic ground truth
uv run python scripts/annotate_real.py --segment seg_kuba --annotator Kuba   # Stage 11: mark lines by hand (GUI)
uv run python scripts/evaluate_real.py               # Stage 11: metrics vs. the manual labels
uv run python scripts/run_pipeline.py --segment all  # Stage 12: whole method on the 3 segments (figures + tables)
uv run python scripts/run_pipeline.py --start 092002 # ... any 2-min window (HHMMSS, --n-files 12)
uv run python scripts/run_pipeline.py --synthetic 42 # ... a synthetic sample (+ metrics vs. GT); --cache, --no-figures
uv run python scripts/tune_parameters.py             # Stage 13: ablation, method comparison, sweeps (~15 min)
uv run python scripts/make_report_figures.py         # Stage 14: flowchart + downscaled figures -> report/figures
uv run python scripts/make_report_figures.py --regenerate   # ... rerun every script above first
uv run jupyter nbconvert --to notebook --execute --inplace report/report.ipynb   # run the report
uv run jupyter nbconvert --to html report/report.ipynb                           # -> report/report.html
uv run pytest                                        # tests (warnings are errors)
uv run jupyter lab                                   # notebooks / report
```

## Layout
- `src/das/` - library code (one module per processing stage)
- `scripts/` - command-line entry points
- `notebooks/` - exploratory notebooks
- `report/` - final report (`report.ipynb` -> `.html`/`.pdf`)
- `docs/` - flowchart, experiment log, references, presentation notes
- `data/`, `outputs/` - data and generated results (not versioned)

See [plan.md](plan.md) for the implementation plan.
