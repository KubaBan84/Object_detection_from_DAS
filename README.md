# Object_detection_from_DAS
Computer vision first project - Detecting Moving Objects in DAS Recordings

Detection of moving vehicles in Distributed Acoustic Sensing (DAS) recordings from the fibre-optic
cable along Jana Pawła II street, **grade-4 version** of the brief (`Project 1 2026.pdf`):
real data only, three continuous 2-minute segments (pair work: two assigned + one own), dataset
analysis, frequency analysis, noise filtering, enhancement of the slanted lines, detection of the
**thick, clearly visible lines** (trams, heavy trucks) and the **velocity** of every detected
object. Classical signal / image processing only (NumPy, OpenCV, scikit-image, Matplotlib) - no
neural networks.

Not part of this version: the thin-line detection (grade 5), the extra points (velocity over time,
clustering) and the interactive GUI required from three-person teams (we are a pair).

## Setup
The project is managed with [uv](https://docs.astral.sh/uv/) (Python 3.12, pinned in `.python-version`).
```bash
uv sync                                   # creates .venv, installs deps + dev group + `das` (editable)
uv run python scripts/extract_data.py     # put the two archives into data/ first (data/README.md)
```
Without uv: `pip install -r requirements.txt && pip install -e .`
(`requirements.txt` is generated by `uv export --no-hashes --no-dev --no-emit-project -o requirements.txt`).

## Usage
```bash
uv run python scripts/run_eda.py                     # Stage 2: dataset statistics + figures
uv run python scripts/run_spectral.py                # Stage 3: FFT / STFT / f-k analysis, band choice
uv run python scripts/run_pipeline.py --segment all  # Stages 4-8 on the 3 segments: figures of every step + tables
uv run python scripts/run_pipeline.py --start 092002 # ... any 2-min window (HHMMSS, --n-files 12)
uv run python scripts/run_pipeline.py --synthetic 42 # ... a synthetic sample (+ ground truth); --cache, --no-figures
uv run python scripts/evaluate_real.py               # Stage 9: real segments vs the manual labels
uv run python scripts/evaluate_synthetic.py          # Stage 9: validation vs the synthetic ground truth
uv run python scripts/annotate_real.py --segment seg_kuba --annotator Kuba   # labelling tool (made the labels)
uv run python scripts/run_experiments.py             # Stage 11: ablation, method comparison, sweeps (~5-10 min)
uv run python scripts/make_report_figures.py         # Stage 12: flowchart + downscaled figures -> report/figures
uv run python scripts/make_report_figures.py --regenerate   # ... rerun every script above first
uv run jupyter nbconvert --to notebook --execute --inplace report/report_compact.ipynb   # run the report
uv run jupyter nbconvert --to html report/report_compact.ipynb                           # -> report_compact.html
uv run jupyter nbconvert --to html --no-input report/report_compact.ipynb                # (code hidden, for the PDF)
uv run pytest                                        # tests (warnings are errors)
```

## Layout
- `src/das/` - library code, one module per processing stage:
  `io` (loading), `stats` (EDA), `spectral` (FFT / STFT / f-k), `preprocessing` (Stage 4),
  `enhancement` (Stage 5), `detection` (Stage 6), `grouping` (Stage 7), `velocity` (Stage 8),
  `evaluation` + `annotation` (Stage 9), `pipeline` (Stages 4-8 end to end), `visualization`,
  `config` (all parameters)
- `scripts/` - command-line entry points (above)
- `tests/` - unit tests
- `report/` - the reports, figures in `report/figures/`:
  - `report_compact.ipynb` / `.html` / `.pdf` - **current, shortened report** (no oriented opening);
  - `report.ipynb` / `.html` / `.pdf` - the earlier, long report, kept frozen with its outputs. It
    describes the earlier detection with the oriented opening and cannot be re-executed with the
    current code. The PDFs are printed from the HTML with the code cells hidden.
- `docs/` - flowchart, experiments log, references, presentation notes
- `data/`, `outputs/` - data and generated results (not versioned)

See [plan.md](plan.md) for the implementation plan and the stage numbers used in the report.
